# Code of Conduct

## Notre engagement

Ce projet est un espace ouvert : physique, contrôle, kernels, drones. Chaque contributeur est traité comme un adulte capable — pas de condescendance, pas de supposition négative sur les compétences d'autrui.

## Règles

1. **Les chiffres d'abord** — une critique d'un résultat se fait par la donnée mesurée, pas par l'autorité ou l'opinion.
2. **L'honnêteté n'est pas négociable** — pas de métrique inventée, pas de benchmark maquillé, pas de régression présentée comme un gain.
3. **Le désaccord est technique** — conteste la preuve, pas la personne. Un désaccord se résout par une expérience (celui qui propose, mesure).
4. **Zéro harassment** — pas d'attaques personnelles, pas de trolling, pas de comportement discriminatoire.

## Application

Signale un manquement à [@bahira](https://github.com/bahira). La sanction est proportionnée : avertissement, puis exclusion du repo.

Le programme

Chaque module est un problème réel, résolu en code, puis confronté à un oracle indépendant — solution analytique, loi de conservation, énumération exhaustive ou différences finies.

MODULE 1 GRATUIT

GPT en 500 lignes

Un transformer de caractère complet — embeddings, attention causale, MLP, layernorm, Adam — en 500 lignes de C. Rien d'autre. Vous l'entraînez sur votre machine et vous regardez la loss descendre.

  • val loss 3.15 en 800 steps (hasard 4.64) · 270k params · ~14 000 tok/s
  • auto-test GEMM 4 chemins : max|diff| 1.4e-6 · gradcheck 0.0044
  • → jouable dans le navigateur (le module C compilé en wasm32, ~150 tok/s)
MODULE 2

La backward exacte

La rétropropagation à la main : dV, softmax-cross-entropy, attention backward, les quatre chemins GEMM. Le gradient analytique confronté aux différences finies centrées.

  • gradcheck à 0.4 % du pire paramètre · parité noyaux 6/6
MODULE 3

Les kernels : exp, rsqrt, tanh, gelu

Écrire exp(x) = 2ᵏ·(1+r·P(r)) à la main. Les polynômes minimax, pourquoi libm est lent, le dispatch runtime AVX2 / scalaire. Le kernel embarqué tourne même sur un Cortex-M0.

  • exp ×3.4 · tanh ×5.6 · gelu ×5.4 vs libm (20M appels) · L∞ 1.48e-5
MODULE 4

Le GEMM multi-accumulateurs

La latence FMA (~4 cycles) masquée par 4 chaînes indépendantes, les tuiles de 8 colonnes, le packing transposé zéro-copie. Et la question qui suit : quand le GEMM n'est plus le frein, par quoi l'est-il ?

  • ×1.78-2.19 vs scalaire naïf (5 formes réelles) · A/B NLv 4→6 : val −0.028 pour ×0.67 tok/s
MODULE 5

La rigueur comme produit

La boucle grounded en production : oracle d'abord, code ensuite. Et ce qu'elle attrape vraiment — pas en théorie. Nous avons reproduit deux papiers 2026 et la vérification a trouvé trois bugs réels avant publication, dont la preuve expérimentale d'un signe inversé (l'objectif explose 47.85 → 81.71 avec le mauvais signe).

  • PNN (Nature Com. 17, 1059) : superposition N+C vérifiée à 2.12e-16 — l'epsilon machine
  • Langevin (arXiv:2506.15121, LBNL) : gradient d'Onsager-Machlup exact à 1.13e-6
  • Et les limites qu'onassume : la génération Langevin ne sépare pas du hasard à petite échelle — documenté, pas caché
